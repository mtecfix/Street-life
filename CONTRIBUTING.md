# Contributing

1. Create a feature branch from `main`.
2. Read `AGENTS.md` and the relevant design document.
3. Keep pull requests focused on one feature or correction.
4. Include acceptance criteria and test evidence in the PR description.
5. Do not commit generated export builds, credentials, or unlicensed assets.
6. Run the project in Godot and validate web export changes before requesting review.

Use conventional commit prefixes where practical: `feat:`, `fix:`, `docs:`, `test:`, `refactor:`, `build:`.
