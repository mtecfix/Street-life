# Character Design

All characters must be original. Build a cast with distinct motivations, routines, speech patterns and relationships.

## NPC data fields
- `npc_id`
- `display_name`
- `role`
- `schedule_id`
- `personality_tags`
- `disposition`
- `relationship_score`
- `known_rumors`
- `dialogue_profile`

Avoid reducing characters to a single stereotype. Give important NPCs competing goals, boundaries and the ability to change their behavior as the world changes.
