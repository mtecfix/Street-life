# Game Design Document

## High concept
Street Hustler is an original urban action-adventure game about navigating a fictional city, building relationships and reputation, completing missions, managing resources, and surviving escalating conflicts.

## Player fantasy
The player begins with limited resources and influence. Through exploration, decisions, relationships and skill, they shape their place in a living neighborhood.

## Core loop
Explore → interact → accept objectives → resolve opportunities and threats → earn resources/reputation → improve capabilities → unlock new areas and stories.

## Perspective
Exploration uses a top-down view. Combat moves to a dedicated arena scene with a focused camera and encounter rules. The arena may use a side-on or angled composition later, but the first implementation uses a clear top-down arena.

## Design pillars
1. **A reactive neighborhood:** NPCs have routines, needs, relationships and memory.
2. **Consequential decisions:** missions and interactions affect reputation, access and future events.
3. **Readable action:** combat feedback, enemy telegraphs and player status must be legible.
4. **Resource tension:** money, health, stamina, equipment and time create tradeoffs.
5. **Emergent stories:** systemic interactions should create situations not limited to scripted quests.

## Initial vertical slice
One fictional block, three enterable locations planned, five NPCs planned, one mission, one hostile encounter, basic cash/inventory, and local save/load. The current sprint is an engineering prototype and uses placeholder geometry.
