# Art Direction

## Visual target
Enhanced 16-bit pixel art: readable silhouettes, limited but expressive palettes, deliberate pixel clusters, selective modern lighting, restrained particles and layered parallax.

## Technical guidance
- Establish a consistent logical resolution and pixel scale before producing final art.
- Use nearest-neighbor filtering for pixel-art textures unless an effect explicitly requires otherwise.
- Keep sprites aligned to the chosen pixel grid.
- Use original artwork or assets with compatible documented licenses.
- Avoid mixing unrelated pixel densities and outline styles.

## Prototype
Current scenes use simple geometric placeholders. These are temporary and should not be mistaken for final art direction.
