# World Design

## Setting
A fictional contemporary urban district. Do not reproduce a real neighborhood map or protected fictional setting. Locations and street names will be original.

## First block
- Main street and two side streets.
- A safe hub.
- A small retail/business interior.
- A residential interior.
- A contested outdoor space.
- Alleys and traversal connectors.

## World simulation
The WorldClock advances game time. NPC schedules and world events subscribe to time changes. Simulation should be deterministic enough to save and restore key state.

## NPC design template
Each NPC should define: stable ID, name, role, schedule, disposition, relationship state, knowledge/rumors, dialogue set, and response rules.
